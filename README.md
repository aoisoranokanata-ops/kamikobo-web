# 紙工房 Web

iPad（Apple Pencil）で使う、日本語の手書きノート・PDF 書き込みアプリ。ブラウザで動き、ホーム画面に追加すればオフラインでも使えます。

**開く:** https://aoisoranokanata-ops.github.io/kamikobo-web/

## いまできること（フェーズ1）
- 本棚: フォルダ・サブフォルダ（何段でも）・移動・名前変更・色・複製・ゴミ箱・並べ替え・名前の検索
- ノート: 用紙テンプレート（無地・横罫・方眼・ドット・コーネル・ToDo・五線譜・原稿用紙）、大きさ・向き・紙の色
- 無限キャンバス
- ボールペン・万年筆・筆ペン（筆圧）・蛍光ペン、消しゴム（部分消し・線ごと）、なげなわ（移動・拡大縮小・回転・色・複製・コピー・切り取り・削除）
- ページの追加・削除・複製・並べ替え・回転
- 2本指でつまんで拡大縮小、2本指タップで消しゴム切り替え（または元に戻す）、3本指タップ
- Apple Pencil を使うと指では描かない（指はスクロール）
- 自動保存（データは端末のブラウザ内）

## フェーズ2
- PDF・画像の読み込み（本棚の「＋ 新規」、またはファイルを落とす）。PDF に手書きで書き込める・拡大してもくっきり
- 文字検索: ノートの中（🔍、当たった所に色）と本棚（ページの中の文字まで探す）
- 画像を貼る（写真・ファイル・貼り付け）。なげなわで移動・拡大縮小・回転
- PDF を挿入・ほかのノートを挿入・結合・分割・ページを選んで抜き出し
- PDF に書き出す（手書きはベクター、元の PDF の文字はそのまま）→ 共有（AirDrop・ファイル）
- ノート・フォルダ・本棚まるごとを .kmkw で書き出し／読み込み（バックアップと復元）

## フェーズ3
- 文字（T）: タップで入力（iPad の手書き入力スクリブルも使える）、大きさ・色・ゴシック/明朝/丸ゴシック・太字
- 付箋・スタンプ（済・重要・★・✓・日付 など）
- 図形補正: 書いたままペンを止めると直線・円・四角・三角・矢印に整う
- 定規（2本指で回転、縁にそって真っすぐ書ける）・レーザーポインター
- 拡大窓: 下に大きく映して小さな字を書く（右端で自動で次へ）
- しおり（PDF の目次になる）・リンク（ページや Web へ。PDF でもリンク）
