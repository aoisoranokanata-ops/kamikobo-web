# 紙工房 Web

iPad（Apple Pencil）で使う、日本語の手書きノート・PDF 書き込みアプリ。ブラウザで動き、ホーム画面に追加すればオフラインでも使えます。

**開く:** https://aoisoranokanata-ops.github.io/kamikobo-web/

## いまできること（フェーズ1）
- 本棚: フォルダ・サブフォルダ（何段でも）・移動・名前変更・色・複製・ゴミ箱・並べ替え・名前の検索
- ノート: 用紙テンプレート（無地・横罫・方眼・ドット・コーネル・ToDo・五線譜・原稿用紙）、大きさ・向き・紙の色
- 無限キャンバス
- ボールペン・万年筆・筆ペン（筆圧）・蛍光ペン、消しゴム（部分消し・線ごと）、なげなわ（移動・拡大縮小・回転・色・複製・コピー・切り取り・削除）
- ページの追加・削除・複製・並べ替え・回転
- 2本指でつまんで拡大縮小、2本指タップで消しゴム切り替え（または元に戻す）、3本指タップ
- Apple Pencil を使うと指では描かない（指はスクロール）
- 自動保存（データは端末のブラウザ内）

## フェーズ2
- PDF・画像の読み込み（本棚の「＋ 新規」、またはファイルを落とす）。PDF に手書きで書き込める・拡大してもくっきり
- 文字検索: ノートの中（🔍、当たった所に色）と本棚（ページの中の文字まで探す）
- 画像を貼る（写真・ファイル・貼り付け）。なげなわで移動・拡大縮小・回転
- PDF を挿入・ほかのノートを挿入・結合・分割・ページを選んで抜き出し
- PDF に書き出す（手書きはベクター、元の PDF の文字はそのまま）→ 共有（AirDrop・ファイル）
- ノート・フォルダ・本棚まるごとを .kmkw で書き出し／読み込み（バックアップと復元）

## フェーズ3
- 文字（T）: タップで入力（iPad の手書き入力スクリブルも使える）、大きさ・色・ゴシック/明朝/丸ゴシック・太字
- 付箋・スタンプ（済・重要・★・✓・日付 など）
- 図形補正: 書いたままペンを止めると直線・円・四角・三角・矢印に整う
- 定規（2本指で回転、縁にそって真っすぐ書ける）・レーザーポインター
- 拡大窓: 下に大きく映して小さな字を書く（右端で自動で次へ）
- しおり（PDF の目次になる）・リンク（ページや Web へ。PDF でもリンク）

## フェーズ4
- テンプレート: 勉強ノート・議事録・コーネル・ToDo・習慣トラッカー・2 段・絵コンテ・原稿用紙
- プランナー: 年間・月間・週間・1 日のページを一気に作成（祝日入り）。日付や「年間・月・週」をタップで移動、PDF でもリンク
- 自作テンプレート: 手持ちの PDF・画像をテンプレートに
- 表紙（色・柄・画像）

## フェーズ5
- 録音（🎙）: 書いた線と音声がつながる。一時停止できる・1 分ごとに途中保存
- 同期再生: 再生に合わせて線が書かれた順に光って現れる。線をタップするとそれを書いた所から再生。速さ変更
- 文字起こし: 録音しながら日本語を文字に（Safari の音声認識）。文字起こしもノート内・本棚で検索できる
- 音声・文字起こしの書き出し

## 1.1
- 図形ツール: ドラッグで直線・矢印・四角・円・三角・ひし形・星など（塗り・「そろえる」で正方形/正円）
- なげなわ: 選ぶ物の絞り込み・タップで選ぶ・四隅で拡大縮小・スクリーンショット・太さ・重なり順
- 定規: 横・縦・45° のボタン、回すつまみ

## 1.2
- Google Drive: 本棚まるごとのバックアップ・バックアップからの復元、ドライブの PDF・画像・.kmkw・Google ドキュメント（PDF にして）の読み込み、
  書き出した PDF などを「☁️ Google Drive」ボタンで保存。保存先はマイドライブの「紙工房 Web」フォルダ
- 使う前に 1 回だけ: Google Cloud で OAuth クライアント ID（ウェブ アプリケーション）を作り、⚙ 設定 → Google Drive に貼る（手順は画面に出ます）
  - 承認済みの JavaScript 生成元: `https://aoisoranokanata-ops.github.io`
  - 承認済みのリダイレクト URI: `https://aoisoranokanata-ops.github.io/kamikobo-web/oauth.html`

## 1.3
- タイマー（⏲、本棚とノートの上の列）: 長さを選んでスタート。予鈴（残り 10・5・3・1 分）、終わった後も超過を数えるタイムキーパー、+1 分・+5 分
- ストップウォッチ（ラップ）
- ポモドーロ: 作業 25 分・休憩 5 分・4 回ごとに長い休憩 15 分（長さは変えられる）。自動で次へ・今日の 🍅 の数
- 終了時アラーム: 音（ベル・電子音・やさしい音）・音量・鳴らす長さ、画面いっぱいのお知らせ。動いている間は画面を消さない
- 動いている間は小さな札に残り時間（ドラッグで動かせる・タップで操作）
- iPad の制限: 紙工房を閉じている間・画面が消えている間は鳴りません（戻った時に「◯分前に終わっていました」と出ます）

## 1.4
- 1 ページずつ表示（画面に合わせて固定）: 払う・画面の右/下の端をタップで次、左/上の端で前（⋯ → 表示）
- ページの並び: 縦・横（ノートごと）
- 目次: しおりと PDF の目次（アウトライン）。ページ全体のサムネイル一覧（上のページ番号をタップ）

## 1.5
- OCR した PDF の文字が検索できなかったのを直した（日本語の文字の対応表を読めていなかった。表示されなかった日本語の文字も出るようになる）
  - 前の版で読み込んだ PDF は、ノートを開くと自動で文字を読み直す。本棚の検索の「PDF の文字を読み直す」でまとめても
- 検索を強化: 字の間の空白・改行を無視（「検 索」「検⏎索」も当たる）、全角/半角・大文字/小文字・部首の字（⾔→言）
  - 見つからない時は カタカナ/ひらがな・濁点・小さい字・OCR で間違えやすい字（力とカ・口とロ・一とー）を同じと見て探し、
    それでも無ければ 1〜2 字違いまで探す（その時は一覧にそう出る）

## 1.6
- 録音の「停止」を押しても反応しないことがあったのを直した（押したらすぐ「保存しています…」、iPad で止まりきらない時も数秒で必ず終わる）
- 🎙 で「録音＋文字起こし」「録音だけ」「文字起こしだけ（音声は残さない）」を選べる。iPad で文字起こしが動かない時は「文字起こしだけ」が確実
- 文字起こしが動かない時は、録音のバーに理由が出る
- 止めた後、文字起こしを「ノートに貼る」（新しいページに文字で。検索もできる）・「テキストで保存」（.txt）。録音の一覧からもできる

## 1.7
- マーカー（蛍光ペン）を引いた所の文字を取り出して箇条書きに: ⤴ 共有 →「🖍 マーカーした所を書き出す」（本棚のノートの ⋯ からも）
  - 形はテキスト（・の箇条書き）・Markdown・表（CSV。Excel・Numbers で開ける）。ページ番号・色ごとにまとめる も選べる
  - ファイルで保存（共有・Google Drive にも）・コピー・ノートに貼る
  - 2 行にまたがって引いた所は 1 つの文に。OCR していないスキャン・手書きの上のマーカーは文字にできない（数だけ知らせる）

## 1.8
- マーカーの書き出し: 黄・赤は上下（行・ページ）に分かれた 1 つの文をつないで 1 件に（行末・行頭の引き損ねも埋める。文が「。」で終わっていれば別）
- 赤は重要（★）。赤の所は文全体（前の「。」の後から次の「。」まで）を取り出せる・赤だけにもできる（自分で選んだ赤も赤として扱う）
- 文の後のページ番号を ON / OFF で選べる（CSV ではページの列）

## 1.9
- マーカーの書き出し: ピンクも赤と同じく重要（★・文全体・上下に分かれた文をつなぐ）
- 引いた所の頭に入った「、」などの記号を取る（「、国政調査権」→「国政調査権」。開きかっこは残す）。終わりの「、」も取る
- 文全体を取り出す時、ページの最初の文も行の始めから取る

## iPad での使い方
Safari で上のアドレスを開き、共有ボタン →「ホーム画面に追加」。
